Guardian settings

Guardian checks sites that are not on its trusted list against PhishTank (free, built in), Google Safe Browsing and VirusTotal. The last two need your own free API keys.

Google Cloud Console → enable the Safe Browsing API → Credentials → API key.

virustotal.com → your profile → API key. The free key allows 4 lookups a minute.

Keys are stored only in this browser (extension storage) and are sent only to Google and VirusTotal. Every site that is not on the trusted list is sent to them for the lookup. Without a key that service is skipped, and the warning page says so.
